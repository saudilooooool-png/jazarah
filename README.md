# 🥕 جَزَرة — مغامرة العائلة

تطبيق يحوّل الروتين اليومي والواجبات إلى **لعبة مغامرات تعاونية (Co-op RPG)** بين الوالدين والأبناء: يصمم الوالد "خريطة المغامرة" ويخوض الابن المهام كبطل يكسب المكافآت.

## 🎯 الفئة المستهدفة (MVP)

**6–12 سنة** (المرحلة الابتدائية)، مع لغة تصميم موجّهة للشريحة 6–9:
أزرار كبيرة، رموز تعبيرية، نصوص قصيرة، واحتفالات فورية عند كل إنجاز.

## 🚀 التشغيل

لا يحتاج التطبيق أي تثبيت أو خادم — افتح الملف `index.html` مباشرة في المتصفح (على الجوال أو الحاسوب).

> تُحفظ كل البيانات محليًا في متصفح الجهاز (localStorage)، فالأفضل استخدام جهاز العائلة المشترك.

## ✨ الميزات

### 🧭 غرفة القيادة (لوحة الوالدين) — محمية برقم سري
- **مكتبة مهام جاهزة (30+ مهمة):** يضيف الوالد المهام بضغطة واحدة من مكتبة مصنفة بخمسة مسارات، مع إمكانية إنشاء مهام مخصصة:
  - 📚 فك شفرة المعرفة (دراسة وقراءة)
  - ⚡ تحدي طاقة البطل (رياضة وحركة)
  - 🛡️ جرعات الطاقة والحماية (عادات صحية)
  - 🌙 نور القلب (صلاة وقرآن وأذكار)
  - 🤝 القلوب الطيبة (مساعدة العائلة والأخلاق)
- **خزنة المكافآت + مكتبة أفكار:** جوائز واقعية بأسعار بالجزر يعتمدها الوالد — إما مخصصة أو من مكتبة أفكار جاهزة (وقت شاشة، مشاوير، حلويات، امتيازات، هدايا) بأسعار مقترحة قابلة للتعديل، مع موافقة الوالد على كل طلب استبدال.
- **نصيحة تربوية يومية 💡** تتغير كل يوم داخل لوحة التحكم، و**مؤشر تحسّن أسبوعي 📈** يقارن إنجاز هذا الأسبوع بالسابق، مع زر **مشاركة تقرير الأسبوع** نصيًا عبر واتساب.

### 👨‍👩‍👧‍👦 حسابات الأطفال (يديرها الوالد فقط)
- **الوالد وحده ينشئ الحسابات** من لوحة الإعدادات المحمية بالرقم السري — الطفل لا يستطيع إنشاء حساب.
- الطفل الجديد يرسل **طلب انضمام 🙋** من شاشة اختيار البطل، فيظهر للوالد ليعتمده بنموذج معبأ باسمه.
- لكل طفل: **اسم مستخدم فريد + بطاقة بطل بها رمز QR 🪪** (للتعريف ولربط المدرسة والمزامنة مستقبلًا)، وبياناته معزولة تمامًا (مهام، جزر، مستوى، سلاسل، تقارير).
- **شاشة اختيار البطل** عند الدخول: كل طفل يضغط بطاقته ويدخل عالمه، ومبدّل أطفال في لوحة الوالد للتنقل بين حساباتهم.

### 🎨 استوديو الأفاتار
- مكتبة **16 شخصية** تُفتح تدريجيًا بالمستويات (4 متاحة من البداية حتى 🐉 في المستوى 12) + 6 خلفيات ملونة.
- الطفل يبدّل شخصيته وخلفيته متى شاء من زر "غيّر شكلي"، ويلبس الأزياء التي اشتراها من المتجر.
- الشخصيات المقفلة تظهر بعلامة 🔒 ومستوى فتحها — حافز إضافي للترقّي.

### 📱 متجاوب مع كل الأجهزة
تخطيط يتكيف مع الجوال (عمود واحد)، والآيباد (بطاقات أوسع وشبكات 3 أعمدة)، والتابلت الكبير (4 أعمدة ولوحة والد بعرض مريح).

### 🤖 المساعد الآلي (الوالد الافتراضي)
للوالدين المشغولين: يحدد الوالد **الأهداف** مرة واحدة (أي المسارات الخمسة) وعدد المهام اليومية (3–6)، ثم يتولى المساعد:
- توليد مهام يومية متنوعة من المكتبة **كل صباح تلقائيًا** مع ضمان مهمة من كل هدف مختار.
- تدوير المهام يوميًا كي لا يملّ الطفل (اختيار حتمي يتغير بالتاريخ).
- المهام اليدوية ومهام المعلمين لا يمسّها — تبقى كما هي.
- دور الوالد ينحصر في متابعة التقارير ومراجعة الإثباتات وقت فراغه.

### 🏫 وضع المدرسة (المعلم / المعلمة)
- من شاشة البداية يدخل المعلم وضعًا خاصًا ينشئ فيه **مهمة أو مكافأة** باسمه.
- يولّد التطبيق **رمز QR + رمزًا نصيًا** (يبدأ بـ `JZR1` مع بصمة تحقق) ويرسله بضغطة عبر واتساب.
- الوالد أو الطفل يلصق الرمز في التطبيق (أو يمسح الـ QR بكاميرا الجوال وينسخ النص) فتُضاف المهمة **موثقة باسم المعلم 🏫** وتظهر شارته في الخريطة والمتجر.
- الرموز التالفة أو المعدلة تُرفض تلقائيًا.
- **تحدي الزعيم 👾:** تحدٍّ أسبوعي تعاوني تسجّل فيه العائلة "ضربات" حتى هزيمة وحش الكسل والفوز بالجائزة الكبرى.
- **صناديق المفاجأة 📦:** إسقاط مكافأة عشوائية تظهر في خريطة الطفل بعد أداء مميز.
- **التقارير 📊:** رسم بياني للإنجاز في آخر 7 أيام وإحصاءات حسب المسار.

### ✅ نظام تأكيد إنجاز المهام
يحدد الوالد لكل مهمة طريقة التأكيد المناسبة:
| الطريقة | كيف تعمل | مناسبة لـ |
|---|---|---|
| 🤝 **ثقة** | الطفل يؤكد بنفسه ويكسب الجزر فورًا | العادات البسيطة (شرب الماء، النوم مبكرًا) |
| 👀 **تأكيد الوالد** | تدخل المهمة قائمة "بانتظار التأكيد" ولا يُصرف الجزر إلا بعد موافقة الوالد | القراءة، الرياضة |
| 📸 **صورة إثبات** | يلتقط الطفل صورة (الغرفة المرتبة، دفتر الواجب) تُرفق بالطلب ويراجعها الوالد ثم يعتمد أو يرفض | الواجبات، ترتيب الغرفة |

- تظهر المهام المعلقة في خريطة الطفل بعلامة ⏳ نابضة حتى يبتّ الوالد فيها.
- عند الاعتماد يحصل الطفل على **احتفال خاص** أول ما يفتح التطبيق ("والدك اعتمد إنجازك! 🎊").
- عند الرفض تعود المهمة متاحة في الخريطة ليعيد إنجازها.
- **للوالد خارج المنزل:** زر «📤 أرسل إنجاز اليوم لوالدي» يشارك تقريرًا نصيًا (✅/⏳/⬜ لكل مهمة + الرصيد والسلسلة) عبر واتساب أو أي تطبيق مراسلة.

### 🦸 عالم البطل (واجهة الطفل)
- **صندوق الكنز اليومي 🪙:** عند أول دخول كل يوم يفتح الطفل صندوقًا فيه جزر عشوائي + مكافأة سلسلة متصاعدة (3 أيام: +3، أسبوع: +7، أسبوعان: +10، شهر: +20) — سبب حقيقي لفتح التطبيق يوميًا.
- **المهمة الذهبية ✨:** كل يوم تُختار مهمة مختلفة تلقائيًا وتتوهج في الخريطة بمكافأة مضاعفة ×2 — عنصر مفاجأة يدفع الطفل لتفقد خريطته صباحًا.
- **خريطة كنز يومية** بمراحل متعرجة، تُختم كل مرحلة بنجمة عند الإتمام مع شاشة احتفال وقصاصات ملونة.
- **أفاتار يتطور** مع المستوى (🐣 → 🐉) وألقاب بطولية ("بطل القراءة"، "سيد اللياقة"…).
- **اقتصاد الجزر:** عملة تُكسب من المهام والسلاسل، وتُنفق على جوائز حقيقية أو عتاد افتراضي للأفاتار.
- **صحة البطل (HP):** العادات الصحية ترفعها، وإهمالها يخفضها.
- **سلسلة الأيام 🔥 (Streaks)** ومكافأة إتمام كل مهام اليوم.
- **10 أوسمة** تُفتح تلقائيًا بالإنجازات.

### ☁️ المزامنة السحابية (Supabase)
- **جهاز الوالد:** من الإعدادات ← "فعّل المزامنة السحابية" ← إنشاء حساب بالبريد وكلمة مرور. يُنشأ تلقائيًا **رمز عائلة** (مثل `JZ7K2MQ4`).
- **أجهزة الأطفال:** من شاشة "أنا البطل" ← "الانضمام برمز العائلة" ← إدخال الرمز — فتصل كل البيانات ويبقى الجهاز متزامنًا.
- الرفع تلقائي بعد كل تغيير (مهلة 2.5 ثانية)، والسحب كل 30 ثانية وعند فتح التطبيق، مع زر "مزامنة الآن".
- مشاركة رمز العائلة عبر واتساب بضغطة، وزر "فحص الاتصال" للتشخيص.

**إعداد لمرة واحدة:**
1. أنشئ مشروعًا في [supabase.com](https://supabase.com) وضع Project URL والمفتاح العلني في أعلى `sync.js`.
2. من لوحة Supabase ← **SQL Editor** ← الصق محتوى `supabase-setup.sql` ← **Run**.
3. (اختياري لتجربة أسلس) Authentication ← Sign In / Providers ← Email ← أطفئ "Confirm email" كي لا يحتاج الوالد تأكيد بريده.

**ملاحظات أمان:** المفتاح العلني (publishable) مصمم للعمل داخل التطبيق ولا يمنح صلاحيات إدارية. رمز العائلة سر مشترك — من يعرفه يصل لبيانات عائلتك، فشاركه مع أفراد العائلة فقط. آلية التزامن "آخر كتابة تفوز" على مستوى العائلة كاملة، وهي مناسبة لعائلة واحدة تستخدم بضعة أجهزة.

## 🗂️ بنية المشروع

| الملف | الوصف |
|---|---|
| `index.html` | هيكل الشاشات (اختيار الدور، الرقم السري، لوحة الوالدين، عالم الطفل) |
| `styles.css` | التصميم الكامل — عربي RTL، متجاوب مع الجوال |
| `app.js` | منطق التطبيق والحالة والتخزين المحلي |
| `qrcode.js` | مكتبة توليد رموز QR — [qrcode-generator](https://github.com/kazuhikoarase/qrcode-generator) (رخصة MIT) |
| `sync.js` | محرك المزامنة السحابية (Supabase عبر fetch — بلا مكتبات) |
| `supabase-setup.sql` | إعداد قاعدة البيانات — يُنفذ مرة واحدة في SQL Editor |
