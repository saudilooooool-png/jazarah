# 🎙️ نصوص صوت جزّور — دليل التسجيل

كل عبارة هنا **ثابتة** لا تتغير، فتُسجَّل مرة واحدة وتُحفظ ملفًا صوتيًا.
العبارات المتغيرة (اسم الطفل، عنوان المهمة، اسم السورة، الأرقام) **تبقى بنطق الجهاز** ولا تُسجَّل.

---

## 1) شخصية الصوت — تُعطى لأداة الذكاء الاصطناعي

| البند | الوصف |
|---|---|
| الشخصية | **جزّور**: تنين جزرة صغير، عمره الظاهري ٦–٨ سنوات |
| الطباع | لطيف · مرح · دافئ · متحمس **بلا صياح** |
| اللهجة | عربية فصحى مبسّطة بلمسة خليجية بيضاء (مفهومة لكل طفل عربي) |
| النبرة | أعلى قليلًا من الطبيعي — صوت طفولي لا صوت راشد |
| السرعة | أبطأ بنحو 10٪ من الطبيعي، مخارج حروف واضحة |
| الإحساس | كأنه صديق يجلس بجانب الطفل، لا معلّم يُلقي تعليمات |
| ممنوع | السرعة · الصراخ · السخرية · نبرة الأمر · صوت رجولي عميق |

**إعدادات مقترحة** لأدوات التوليد (تُعدَّل حسب الأداة):
الثبات ≈ 50٪ · التشابه ≈ 75٪ · المبالغة الأسلوبية منخفضة–متوسطة · السرعة ≈ 0.9×

> **مهم:** سجّل كل العبارات بـ**صوت واحد** — هذا الصوت هو هوية جزّور.
> إعدادات «شخصيات الصوت الثلاث» داخل التطبيق تخصّ النطق الآلي للنصوص المتغيرة فقط.

---

## 2) المواصفات التقنية للملفات

| البند | القيمة المطلوبة |
|---|---|
| الصيغة | **MP3** (يعمل على أندرويد وiOS والمتصفح بلا استثناء) |
| القنوات | **Mono** (أحادي) |
| التردد | **44100 Hz** |
| معدل البت | **96 kbps CBR** |
| مستوى الصوت | **‎-16 LUFS** متكامل · الذروة الحقيقية ≤ **‎-1.5 dBTP** |
| الصمت | ≤ 50ms في البداية · ≤ 200ms في النهاية |
| المؤثرات | **بلا** موسيقى · بلا صدى · بلا فلاتر |
| مدة العبارة | ١–٣ ثوانٍ (٤ كحد أقصى) |
| اسم الملف | **المعرّف حرفيًا** بأحرف إنجليزية صغيرة + `.mp3` |
| المسار | `audio/prompts/ar/<المعرّف>.mp3` |
| حجم المجلد | يُفضّل ألا يتجاوز **1.5 ميجابايت** إجمالًا |

**مثال:** العبارة رقم ١ تُحفظ باسم `cheer.mp3` داخل `audio/prompts/ar/`.

⚠️ **الاسم يجب أن يطابق المعرّف تمامًا** — حرف واحد مختلف يعني أن الملف لن يُشغَّل.
الملف الناقص لا يعطّل شيئًا: التطبيق ينطق النص آليًا بدلًا منه.

## 4) ما لا يُسجَّل — يبقى بنطق الجهاز

هذه تتغير حسب الطفل والمحتوى، فيستحيل تسجيلها:

- عناوين المهام: «إنهاء الواجبات المدرسية…»
- أسماء الأطفال في التحيات
- آيات القرآن وأسماء السور (تُتلى بصوت الشيخ من مصدرها)
- فصول حكاية جزّور الثمانين
- كلمات لعبة الحروف وأسئلة الحساب
- أسماء الجوائز في المتجر والأرقام والمبالغ

---

## 5) خطوات التسليم

1. ولّد الملفات الـ٤١ بالمواصفات أعلاه.
2. سمِّ كل ملف بمعرّفه بالضبط: `cheer.mp3` · `poke1.mp3` … إلخ.
3. ارفعها في مجلد `audio/prompts/ar/` داخل المستودع.
4. أبلغني — سأضيفها لقائمة التخزين المؤقت وأختبرها وأدفع نسخة جديدة.

**لا حاجة لتسليمها دفعة واحدة.** ابدأ بالأهم إن أردت التجربة أولًا:
`cheer` · `poke1` · `poke2` · `poke3` · `drag1` · `heart` · `done` · `chest`
